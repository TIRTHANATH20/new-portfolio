# Tirtha Nath — Product & AI Generalist Portfolio

> Designing interfaces and building intelligent systems.

Personal portfolio website showcasing digital product designs in Figma alongside applied machine learning and agentic AI systems in Python. Co-author of two IEEE conference papers.

## 🚀 Overview

This repository houses the source code and design assets for Tirtha Nath's product portfolio. The site is crafted with an editorial, dark-mode aesthetic featuring an interactive 3D WebGL particle wave canvas, fluid responsive typography, and high-contrast typography.

### Highlights
- **UI/UX Product Prototypes**: 5 multi-screen mobile flows designed in Figma with verified 11-page Eduversity design documentation.
- **Applied AI & Systems**: Agentic workflows (MCP, A2A protocols), adaptive reinforcement learning traffic algorithms, real-time edge computer vision, and automotive predictive maintenance.
- **IEEE Research**: 2 published IEEE conference papers in intelligent transportation and multi-agent coordination.
- **Enterprise Credentials**: Certified in SAP Generative AI Developer, Oracle Cloud ERP, and IITM Pravartak VLSI.

## 💻 Local Development

Run the portfolio locally with any static web server:

```bash
# Clone the repository
git clone git@github.com:TIRTHANATH20/new-portfolio.git

# Navigate into the project directory
cd new-portfolio

# Start a local HTTP server (Python 3)
python3 -m http.server 8080

# Open in your browser
open http://localhost:8080
```
